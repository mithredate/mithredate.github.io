agentic coding

I use Claude Code every day and keep looking for better ways to work with it. When something works, I share it with my team and other engineers at Roadsurfer.

  • I set up Roadsurfer's Claude Code plugin marketplace for engineering. More than ten engineers have contributed so far.
  • I created the AI fluency framework, and it's now part of our engineering career framework.

The best thing I've built for this is orchestrate (opens in a new tab), a planning skill based on Matt Pocock's wayfinder. It takes a project that's too big for one agent session and breaks it into small decisions. Once those are made, agents build it. A second agent reviews each change and a third re-runs the tests. Anything that needs a human, like a deploy, waits for me.
